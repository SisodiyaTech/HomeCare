## 🛠️ How to Re-generate Screenshots
To re-run and refresh all screenshots automatically anytime UI changes are made:
```powershell
# 1. Start preview server (if not already running)
npm run preview -- --port 4173

# 2. Run capture script
node take-all-screenshots.mjs
```
All screenshots will be automatically saved to `./DesignSS/` and mirrored to `../DesignSS/`.
